# Glossary

- **Corpus**: collection of documents selected for systematic analysis.
- **Curated source**: a source explicitly selected by the project rather than found by open web search.
- **Discovery**: method used to identify posts belonging to a source, such as RSS, sitemap, archive page, or manual URL.
- **Ingestion**: downloading a selected document and bringing it into the project.
- **Normalization**: converting documents from different websites into a common textual form.
- **Provenance**: information recording where a document came from and when it was retrieved.
- **Hash**: short deterministic fingerprint of content. Atlas uses SHA-256 to detect content changes.
- **Incremental processing**: processing only new or changed documents.
- **Structured extraction**: converting unstructured text into named fields such as thesis, mechanisms, evidence, and concepts.
- **JSON Schema**: machine-readable contract describing the required shape of JSON output.
- **Semantic processing**: using a language model to interpret meaning rather than merely manipulate characters.
